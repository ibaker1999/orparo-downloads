# Orparo downloads

Installer files for [Orparo](https://orparo.com), the Mac app that builds Ableton Live sets for church worship teams.

Get Orparo from **[orparo.com](https://orparo.com)**. This repository only holds the signed, notarised installer files that the website links to. There is no source code here.
